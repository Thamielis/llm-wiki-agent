## Summary
This article is a beginner-friendly primer on PowerShell objects, centered on how to discover, inspect, and manipulate them. It covers `Get-Member`, properties, aliases, methods, custom objects, object comparison, and adding or removing members.

## Key Claims
- Nearly everything in PowerShell is an object, not plain text
- `Get-Member`, `Select-Object`, `Where-Object`, `Compare-Object`, and `Add-Member` are core tools for working with objects
- Custom objects can be created from hashtables and extended with new members as needed
