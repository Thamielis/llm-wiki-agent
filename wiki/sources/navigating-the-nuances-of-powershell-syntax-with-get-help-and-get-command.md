## Summary
This source presents `Get-Help` and `Get-Command` as the primary tools for learning PowerShell syntax and command behavior. It frames the pair as a practical way to inspect syntax, discover parameters, and reduce guesswork while working in the shell.

- `Get-Command` helps discover available commands and their parameter sets

- Help-driven discovery reduces reliance on memorization
